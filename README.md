# 🌐 Python Port Status Checker

## 📌 Project Overview
The Python Port Status Checker is a basic networking and cybersecurity project that checks TCP connectivity on a specified IP address and port number.

It uses Python socket programming to determine whether a TCP connection can be established.

## 🚀 Features
- IP address input
- Port number input
- TCP connection testing
- Open port detection
- Closed connection detection
- Connection timeout handling
- Error handling

## 🛠️ Technologies Used
- Python 3
- Socket Programming
- TCP/IP Networking

## ▶️ How to Run

1. Install Python 3.
2. Download or clone this repository.
3. Open the terminal in the project folder.
4. Run:

```bash
python port_status_checker.py
```

## 🧪 Example Input

```text
Enter Target IP: 127.0.0.1
Enter Port Number: 443
```

## 📊 Possible Results
- OPEN: TCP connection established successfully.
- CLOSED: Target refused the connection.
- TIMEOUT: Connection timed out.
- UNKNOWN: Connection status could not be determined.
